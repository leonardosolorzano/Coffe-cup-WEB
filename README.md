 # Coffee Cup ☕

Sitio web de una cafetería online pensado para presentar el menú, destacar productos y ofrecer una experiencia sencilla y agradable a los amantes del café.

## Características

- Catálogo de cafés, bebidas y productos de cafetería.
- Presentación clara y visual de los productos.
- Diseño adaptable a dispositivos móviles y escritorio.
- Navegación sencilla e intuitiva.
- Sección de contacto para consultas y pedidos.

## Tecnologías

Este proyecto está desarrollado con tecnologías web modernas. Consulta los archivos del proyecto para conocer el stack utilizado.

## Instalación

1. Clona el repositorio:

	```bash
	git clone <URL_DEL_REPOSITORIO>
	```

2. Accede al directorio del proyecto:

	```bash
	cd Coffe-cup-WEB
	```

3. Instala las dependencias, si corresponde, y ejecuta el proyecto con el comando definido por la configuración del proyecto.

## Uso

Abre la aplicación en el navegador para explorar el menú y conocer la propuesta de Coffee Cup.
